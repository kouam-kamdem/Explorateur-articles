# Explorateur-articles

## Démo en ligne
[Voir l'application en ligne](https://explorateur-articles.vercel.app/)

## Description
Une application React permettant d'aller chercher des articles de blog depuis un serveur (passant par un fetch(...)) , affiche ceux-ci en lien cliquable,puis affiche le titre et le corps de l'article sur lequel on a cliqué .

## Technologies
React, Vite, React Router
 
 ## Fonctionnalités
 - Cliquer sur un article 
 - Voir le titre et le corps de l'article cliqué
 - Signaler les adresses inexistantes avec un message ("Adresse introuvable")
 - Afficher "chargement..."lors du chargement des données

## Ce que j'ai appris
le routing, les routes dynamiques, le fetch, async/await, et les 3 états (Data, Loading, Error)

## Comment lancer le projet
Les commandes:
```bash
npm install
npm run dev
``` 
puis ouvrir http://localhost:5173/
